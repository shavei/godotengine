# Pass It On (working title)

A 2D top-down action roguelite RPG about a hero and a village that grow together, built in Godot 4.

**Every power you earn, you can keep, or give to a villager forever.** Villagers train the powers you give them, and when they master one they teach you a permanent Technique.
